> The app your friend wants already exists as a napkin sketch in their pocket, so show it to an AI agent on make.fun and get the real thing before the ink fades.

A single-sentence pitch for a friend who has never coded, convincing them to let an AI agent on make.fun build their first app idea. The pitch's angle: the app already exists — as a napkin sketch in their pocket — so all that's left is to show it to the agent and get the real thing before the ink fades.

Run it with:

```sh
python3 main.py
```

It validates the pitch (one sentence, at most 240 characters) and writes it to `/output/entry.txt`.
